HTML

CSS

JAVA SCRIPT

JavaScript est un langage de programmation permettant d'implémenter des fonctionnalités complexes sur des pages web.

PHP

PHP (Hypertext Preprocessor) est un langage de script serveur utilisé principalement pour le développement web afin de produire des pages web dynamiques.

Python est un langage de programmation interprété, polyvalent et de haut niveau, connu pour sa simplicité et sa lisibilité.

Java est un langage de programmation orienté objet, conçu pour être portable et indépendant des plateformes, utilisé largement pour le développement d'applications web, mobiles et d'entreprise.

Spring Boot

Spring Boot est un framework Java open source qui simplifie le développement d'applications en fournissant des configurations par défaut et des outils pour créer des applications Spring autonomes et prêtes pour la production.

JPA

JPA (Java Persistence API) est une spécification Java qui facilite la gestion des données relationnelles en mappant des objets Java à des bases de données relationnelles.

Hibernate

Hibernate est un framework de mapping objet-relationnel (ORM) pour Java qui simplifie l'interaction avec les bases de données en mappant des objets Java à des tables de bases de données.

Maven

Maven est un outil de gestion et d'automatisation de construction de projets Java, qui gère les dépendances, la configuration et le cycle de vie des builds.

MySQL

MySQL est un système de gestion de base de données relationnelle open source, largement utilisé pour le stockage, la gestion et la manipulation des données.

Git

Git est un système de gestion de versions décentralisé permettant de suivre les modifications du code source et de collaborer efficacement sur des projets de développement logiciel.

GitHub

GitHub est une plateforme de développement collaboratif basée sur Git, offrant des fonctionnalités de gestion de versions, de partage de code et de collaboration en ligne.

GitLab CI/CD

GitLab CI/CD est une fonctionnalité de GitLab qui permet l'intégration continue et la livraison continue pour automatiser le processus de build, test et déploiement d'applications.

WordPress

WordPress est un système de gestion de contenu (CMS) open source qui permet de créer et de gérer facilement des sites web et des blogs.

VirtualBox

VirtualBox est un logiciel de virtualisation open source permettant de créer et d'exécuter des machines virtuelles sur divers systèmes d'exploitation.

Linux(Ubuntu)

Linux (Ubuntu) est une distribution open source du système d'exploitation Linux, connue pour sa facilité d'utilisation, sa stabilité et son orientation vers les utilisateurs et développeurs.
